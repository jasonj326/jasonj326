Learning blocks are booked first; building gets what's left — that ordering is the whole defence. Every session ends with code I wrote or verified, not watched. Watching is not a session.

The guardrailThe illusion of the vibe-coding builder

Directing an AI to build produces real artifacts and no transferable capability — the ability is borrowed, and the bill arrives the moment I have to verify, maintain or extend it on my own.

The tell: if I can't explain last session's code in plain language, that was consumption, not building.
