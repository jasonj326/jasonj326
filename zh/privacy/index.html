我不追蹤你

這是一個寫給人讀的個人網站，不是用來分析人的。沒有 Google Analytics、沒有 Mixpanel、沒有 Plausible、沒有 cookie、信件裡沒有開信追蹤、沒有點擊包裝。你來、你讀、你走——我這邊不會留下任何關於你來訪的紀錄。

有幾個窄例外，全部都需要你主動操作才會發生。下方一一列出。

我會收集什麼

如果你訂閱電子報，我會收到你的 email 與選填的「來源」欄位（你從哪一頁訂閱的）。表單由 Formspree 或 Google 表單託管；提交內容會轉寄到我的信箱，並儲存在 Formspree 後台或 Google 雲端硬碟。

如果你跟 Lia 聊天（網站上的 AI 助理），你的訊息會送到 Anthropic 的 Claude API 處理。我在 Cloudflare KV 命名空間裡每天記錄聚合的對話與訊息計數——只是數字，不含內容。我不記錄對話本身。

主題偏好：你選擇的淺色或深色模式會存在你瀏覽器的 localStorage，再次造訪時會記得。這個資料完全不會離開你的裝置。

如果你透過加密貨幣支持我，我會看到你的錢包位址（或你交易所出金錢包的位址），但原則上我不會知道你是誰。

就是這樣，沒了。

我不做的事

  • 不放任何 analytics 腳本。
  • 不用 cookie。瀏覽器端唯一的 persistence 是上面提到的 localStorage 主題鍵。
  • 寄出的信件裡不埋開信追蹤像素。
  • 連結上不放點擊追蹤。
  • 不用會分析你的第三方字型、嵌入元件、腳本。（圖示與 Tailwind/Lucide CDN 是當作靜態檔案抓取的；CDN 看到你的 IP 是因為 HTTP 本身就會這樣。）
  • 不販售、不出租、不為了行銷把你的資料分享給第三方。

收集到的東西我怎麼用

  • Email 地址：依你選擇的表單，保留在 Formspree 訂閱清單或 Google 表單中；用來寄送個人動態，例如季報、活動、邀約。如果你透過 Substack 訂閱，我的寫作會經由 Substack 送到你信箱。
  • Lia 對話計數：我看得到聚合的 KV 數值，用來抓使用量（避免撞到 Anthropic API 的每日上限）。沒有任何個別使用者的資料。

政策異動

如果有實質改動——新增第三方服務、新增收集點——我會更新最上方的「最後更新」日期；如果改動會影響既有訂閱者，我會寄信先告知。歷史版本在 git history 裡。
