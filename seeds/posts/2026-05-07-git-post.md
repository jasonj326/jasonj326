Git 指令樹狀圖（cheat sheet）

---

標準完整流程

```
1. git pull                               ← 動工前
2. (改 .md 檔)
3. git add seeds/posts/<你改的檔>.md      ← 具名 add，不要 .
4. git diff --cached                      ← 確認改對 (按 q 退出)
5. git commit -m "意義明確的 message"
6. git push                               ← 沒被拒就完成
```


1. `git pull`

```
git pull
├─ ✅ "Already up to date"
│     → 繼續做事
│
├─ ✅ "Updating ... Fast-forward" 或 "Successfully rebased"
│     → 成功，繼續做事
│
├─ ❌ "cannot pull with rebase: You have unstaged changes"
│     → 你有未 commit 的改動擋住
│     → 跑：git stash && git pull && git stash pop
│
├─ ❌ "CONFLICT (content): Merge conflict in seeds/seeds.json"
│     → seeds.json 你跟 Actions 都改了
│     → 跑：python3 scripts/build-seeds.py
│            git add seeds/seeds.json
│            git rebase --continue
│
└─ ❌ "Need to specify how to reconcile divergent branches"
      → 沒設 pull.rebase
      → 跑：git config pull.rebase true
             git pull
```

---

2. `git add seeds/posts/`

```
git add seeds/posts/
├─ ✅ 無輸出
│     → 成功（git 沒消息就是好消息）
│
└─ ❌ "fatal: pathspec 'X' did not match any files"
      → 檔名/路徑打錯
      → 跑：git status   ← 看實際檔名再 add
```

---

3. `git diff --cached`

```
git diff --cached
├─ ✅ 顯示一堆 + - diff
│     → 看完按 q 退出 less
│     → 確認你的改動沒問題就繼續
│
└─ ✅ 沒輸出
      → 沒東西 staged。回去檢查 git add 有沒有跑
```

---

4. `git commit -m "Seeds update"`

```
git commit -m "Seeds update"
├─ ✅ "[main abc1234] Seeds update"
│   "N files changed, X insertions(+), Y deletions(-)"
│     → 成功
│
├─ ❌ "nothing to commit, working tree clean"
│     → 你還沒 git add，或檔沒真的改
│     → 跑：git status   看狀況
│
└─ ❌ "nothing added to commit but untracked files present"
      → 你的檔是「新檔」沒 add
      → 跑：git add seeds/posts/<檔名>.md
             git commit -m "..."
```

---

5. `git push`

```
git push
├─ ✅ "Writing objects ... main -> main"
│     → 成功，~20 秒後網頁更新
│
├─ ✅ "Everything up-to-date"
│     → 沒新 commit 要送（你之前已經 push 過了）
│
└─ ❌ "rejected" / "non-fast-forward"
      → origin 比你新（多半是 Actions auto-commit）
      → 萬用解：git stash && git pull && git stash pop && git push
```

---

卡住萬用解（背 1 行）

任何時候 push 失敗、pull 卡住、不知所措：

```
git stash && git pull && git stash pop && git push
```

意思：暫存未 commit 改動 → 拉最新 → 還原 → 推上去。

99% 的卡關都這 1 行解決。

---

看狀況用這 2 行

```
git status              ← 哪些檔改了，哪些 staged
git log --oneline -5    ← 最近 5 個 commit（看你跟 origin 誰新）
```
